# 完整研究报告提纲

**暂定标题：** AI Coding Agent 产品生态、竞争格局与人才需求研究（2026）

## 摘要

- 研究目的与范围
- 方法、样本和数据日期
- 5—8条核心结论
- 对产品、企业采用和人才策略的主要启示
- 研究限制

## 1. 研究背景

### 1.1 从代码补全到任务委派

说明 Coding Assistant、Coding Agent 和 Agentic Development Workflow 的差异。

### 1.2 研究问题

- 产品能力如何分层；
- 用户价值如何产生；
- 企业竞争优势如何形成；
- 人才需求如何变化。

### 1.3 研究方法与限制

- 桌面研究
- 产品体验
- 岗位内容分析
- 三角验证
- 时效性和样本偏差

## 2. 产品生态地图

### 2.1 产品形态

- AI-native editor
- CLI / terminal agent
- Repository / cloud agent
- Autonomous software engineering agent
- Browser-based app building agent
- Open-source / self-hostable agent
- Enterprise developer platform

### 2.2 工作流入口

比较 IDE、终端、代码托管平台、浏览器和异步云端委派的差异。

### 2.3 目标用户与典型任务

- 独立开发者
- 企业工程师
- 产品经理与非专业开发者
- 内部效率和平台团队

## 3. 产品能力比较

### 3.1 任务理解与规划
### 3.2 代码库理解与上下文管理
### 3.3 多文件修改和工具调用
### 3.4 测试、Review与错误恢复
### 3.5 人机协作与权限控制
### 3.6 扩展生态和企业治理
### 3.7 成本、速度和监督负担

输出：

- 产品能力矩阵
- 场景化测试结果
- 典型成功案例与失败模式
- 不同用户类型的适配建议

## 4. 用户需求与采用障碍

### 4.1 用户需要购买的不是“生成代码”

分析时间节省、认知负担、可控性、质量和协作价值。

### 4.2 不同用户的需求差异

- 新手与专家
- 个人项目与企业代码库
- 快速原型与长期维护
- 同步协作与异步委派

### 4.3 不信任与放弃使用的原因

- 输出不稳定
- 上下文误解
- 变更范围失控
- 缺少验证证据
- 价格和额度不可预测
- 数据、安全和合规顾虑

### 4.4 采用成熟度模型

从个人试用到组织级Agent平台和治理体系。

## 5. 公司与竞争格局

### 5.1 玩家类型

- 模型厂商
- 开发工具公司
- 代码托管与开发平台
- 云平台
- 自主软件工程Agent公司
- 开源社区

### 5.2 竞争资源

- 模型能力
- 上下文与代码索引
- Agent Runtime和工具链
- IDE、GitHub或云平台入口
- 企业客户和渠道
- 数据、评测与反馈闭环
- 安全、权限和治理能力

### 5.3 商业模式

- 订阅
- 席位制
- 额度/积分
- 按任务或按量计费
- 企业合同
- 开源与托管服务

### 5.4 战略分组与案例

对Tier A公司进行重点案例分析，并对区域市场和开源工具设置对照组。

## 6. 人才生态与岗位地图

### 6.1 岗位族群

- AI Product Management
- Agent Engineering
- Developer Tools Engineering
- AI Evaluation and Quality
- Enterprise AI Platform
- AI Solutions and Adoption
- Developer Relations
- AI Strategy and Market Research
- AI Talent Strategy and Mapping
- AI Security and Governance

### 6.2 能力模型

分为：

- 技术与AI理解
- 产品与用户研究
- 商业与战略分析
- 数据与研究方法
- 沟通与跨团队推进
- 英语和全球信息获取

### 6.3 目标公司Mapping

- 公司类型与发展阶段
- 代表产品
- 相关部门和岗位
- 可能的人才来源
- 稀缺能力和招聘难点

### 6.4 岗位样本内容分析

对公开职位描述进行编码，统计职责和能力标签的出现频率及组合关系。

## 7. 战略结论

计划回答：

1. Coding Agent的主要竞争壁垒是否正在从模型转向工作流和分发？
2. 企业级价值是否取决于验证、权限和治理，而非单次生成效果？
3. 通用Agent、Coding Agent和传统开发工具将如何分工？
4. 哪些岗位将成为AI应用和开发工具公司的关键人才？
5. 人才战略团队应如何建立目标公司、岗位族群和候选人画像？

### 8.1 产品与业务团队

- 选择研究、试点和评估方法
- 设计内部AI工具和治理机制

### 8.2 人才战略与招聘团队

- 岗位定义
- 目标公司分层
- 能力评估
- 人才池维护

### 8.3 学生与早期职业候选人

- 技术、产品、研究和业务能力的组合
- 可验证作品集设计
- 如何避免只罗列AI工具名称
