# AI Coding Agent Landscape 2026

> AI Coding Agent 产品生态、用户需求、竞争格局与人才需求研究。

**研究状态：** Phase 1 / Research Design  
**研究快照日期：** 2026-07-30  
**主要语言：** 中文（关键术语保留英文）

## 项目目的

本项目试图回答四组问题：

1. **产品：** AI Coding Agent 正在覆盖软件开发流程中的哪些环节，不同产品的能力边界和竞争壁垒是什么？
2. **用户：** 独立开发者、企业工程师、产品经理与内部效率团队分别需要什么，采用或放弃 Coding Agent 的原因是什么？
3. **公司：** 模型厂商、开发工具公司、云平台与创业公司如何构建差异化优势？
4. **人才：** AI 应用、开发者工具与 Agent 业务需要哪些岗位和能力，企业的人才来源与招聘重点如何变化？

## 预期产出

- 产品与公司 Mapping 数据集
- 统一的产品能力评价框架
- 公开招聘岗位样本与能力标签体系
- AI Coding Agent 人才角色地图
- 执行摘要与完整研究报告
- 可复核的来源清单与研究限制说明

## 研究原则

- 优先采用产品官方文档、公司公告、公开招聘页面和可验证的一手材料。
- 将“官方宣称”“第三方证据”“个人使用观察”和“研究者判断”分开记录。
- 所有评分必须保留证据与置信度，不以单一排行榜替代情境化判断。
- 对快速变化的产品功能、价格和岗位信息标注采集日期。
- 人才 Mapping 仅使用公开职业信息，不收集私人联系方式或敏感个人数据。

## 当前阶段

Phase 1 重点是建立可复核的研究基础设施：

- 明确研究问题、样本边界和分析单位；
- 建立产品能力与企业采用评价模型；
- 设计产品、公司、岗位和人才角色数据表；
- 形成正式报告目录和待验证假设。

本阶段不发布未经验证的综合排名，也不把产品营销材料直接视为事实结论。

## 作者与贡献

项目由仓库所有者主导研究问题、样本选择、个人使用观察与最终判断；AI 工具用于公开资料整理、结构化分析、初稿生成和一致性检查。所有进入主分支的结论均应经过人工审核。

## Disclaimer

本项目为独立研究作品，不代表任何产品公司或雇主。产品功能、价格、组织架构和招聘信息可能随时间变化，使用数据时请核对采集日期与原始来源。
